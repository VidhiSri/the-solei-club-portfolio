# The Solei Club

A responsive, static portfolio site reproduced from the supplied Canva design captures. All original imagery and visual content are kept in `canva_design/`.

## Run locally

```sh
npx serve .
```

Then open the local URL printed by `serve` (usually http://localhost:3000).

This is a static site and can be deployed to Cloudflare Pages or another static host. Set the project root to this directory; no build command is required.
