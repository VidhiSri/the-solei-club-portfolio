# The Solei Club

A responsive, static portfolio site based on the connected Lovable design. Original photography and the Solei Club logo are stored locally in `assets/`; the original Canva captures are retained in `canva_design/`.

## Run locally

```sh
npx serve .
```

Open the local URL printed by `serve` (usually http://localhost:3000). The site needs no build step and can be deployed to Cloudflare Pages or another static host.
